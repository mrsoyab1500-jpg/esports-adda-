# ESPORTS ADDA – Flutter prototype

This is a starter Flutter app for Android and iOS.

## Included
- Dark black + neon-green esports theme
- Home screen
- Tournament list with sample free tournaments
- Join button with in-memory demo registration
- Sample leaderboard
- Player profile screen
- Bottom navigation

## Run
1. Install Flutter SDK and Android Studio (for Android) or Xcode (for iOS).
2. Extract this folder.
3. In the project folder, run:
   - `flutter pub get`
   - `flutter run`

## Important limitations
- This is a UI prototype, not a production app.
- Tournament registrations reset when the app restarts.
- Login, cloud database, admin dashboard, live results, room credentials,
  notifications, and deployment are not implemented yet.
- Leaderboard values and tournaments are sample data.
- No payments, cash prizes, deposits, or withdrawals are included.
- Before any future real-money features, obtain legal advice and check
  current Indian laws, app-store rules, and game publisher permissions.
- Check Garena/Free Fire branding and tournament policies before public launch.
